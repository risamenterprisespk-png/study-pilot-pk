PDF Compressor

Reduce PDF file size by re-encoding pages.

How to use the pdf compressor

  1. Choose your PDF file.
  2. Pick a quality: Smallest, Balanced or Best quality.
  3. Press “Compress PDF” and download compressed.pdf.

How it works

Each page is rendered and saved again as a compressed image. This can cut size sharply for scans and image-heavy files, but text is no longer selectable afterwards.

Your input stays in your browser. Nothing is uploaded to a server.

Tips for best results

  • Start with Balanced and compare the file sizes before trying Smallest.
  • It works best on scanned or image-heavy PDFs. PDFs that are mostly text are already small.
  • Keep your original file, because the compressed copy cannot be edited as text.

Common uses

People compress PDFs to fit email attachment limits, to meet the size limits on application and visa portals, and to share scans over messaging apps without long upload times.

Limitations

Each page is saved again as a compressed image, so text can no longer be selected or searched in the compressed file and links stop working. Use it for sharing, not for documents you still need to edit.

FAQ

Why did my file get bigger?

Files that are already well optimized can grow. Try a lower quality setting.

How much smaller will my PDF be?

It depends on the content. Scans and photo-heavy files often shrink a lot, while text-only files may barely change.

Will the quality get worse?

Slightly. Best quality keeps the most detail, and Smallest trades detail for size.

Can I compress a PDF and then merge it?

Yes. Compress each file first, then combine them with the PDF merger.
