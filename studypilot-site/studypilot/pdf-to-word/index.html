PDF to Word

Extract the text of a PDF into a Word-compatible file.

How to use the pdf to word

  1. Choose your PDF file.
  2. Press “Convert to Word”.
  3. Open the downloaded .doc file in Word or another word processor and edit the text.

How it works

The tool reads the selectable text from each page and saves it as a .doc file. Layout, tables and images are not preserved, and scanned PDFs without text need OCR, which is not supported.

Your input stays in your browser. Nothing is uploaded to a server.

Tips for best results

  • It works on PDFs that contain real text, such as ones exported from Word or Google Docs. If you can select text in the PDF, it should convert.
  • Expect to reapply headings, tables and images yourself, and proofread the result.
  • For scanned pages, use a tool with OCR first, since this tool cannot read images of text.

Common uses

Use it to reuse text from a report, edit a handout or worksheet, copy your own CV text into a new template, or pull quotes from a document into your notes.

Limitations

Only the text is extracted. Layout, tables, columns and images are not preserved, and scanned PDFs without selectable text cannot be converted.

FAQ

Does it work on scanned PDFs?

No. Scanned pages contain images, not text.

Why is my formatting missing?

The tool extracts plain text from each page, so layout, fonts, tables and images are not carried over.

Will the file open in Microsoft Word?

Yes. It is saved as a Word-compatible .doc file that opens in Word and most word processors.

Is there a page limit?

There is no fixed limit, but very large PDFs depend on your device’s memory.
