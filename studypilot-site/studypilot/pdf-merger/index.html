PDF Merger

Combine several PDF files into one, right in your browser.

How to use the pdf merger

  1. Click the file box and select two or more PDF files.
  2. Press “Merge PDFs”.
  3. Your browser downloads a single file named merged.pdf with all pages in order.

How it works

Select two or more PDFs in the order you want them; pages are copied into one new file. Everything runs on your device, so confidential documents stay private.

Your input stays in your browser. Nothing is uploaded to a server.

Tips for best results

  • The order follows the order your file picker returns the files, which is usually alphabetical. If order matters, rename the files 01, 02, 03 before selecting.
  • Password-protected PDFs cannot be merged, so remove the protection first.
  • If the result is large, run it through the PDF compressor afterwards.

Common uses

Merging is useful for combining assignment sections into one submission, joining a CV with certificates for a job application, bundling scanned pages, or putting several invoices into one document.

Limitations

Pages are copied into a new file, so interactive features such as bookmarks and form fields may not carry over. Very large files depend on your device’s memory.

FAQ

Is there a file size limit?

No fixed limit, but very large files depend on your device's memory.

Can I merge more than two PDFs?

Yes. Select as many files as you need in one go.

Will the page order inside each file change?

No. Each file’s pages stay in their original order, and the files follow one another.

Are my PDFs uploaded to a server?

No. The files are merged in your browser and never leave your device.
