MCQ Generator

Create multiple-choice questions with an answer key.

How to use the mcq generator

  1. Paste your study material, or upload a PDF.
  2. Choose the number of questions, from 1 to 20.
  3. Press “Create MCQs” to get questions with options A to D, followed by an answer key.

How it works

Each question hides a key term from a sentence of your text and offers it among three distractor terms taken from the same document, followed by an answer key.

Your input stays in your browser. Nothing is uploaded to a server.

Tips for best results

  • Use a page or more of text so the tool has enough different terms to build wrong options from.
  • Check each question before using it in a real test, since distractors come from the text and may occasionally also fit.
  • Shuffle or rewrite questions if you are using them with a class.

Common uses

Practise for exams, make a quick revision test from your notes, or draft starter multiple-choice questions that you then edit.

Limitations

Each question hides one key term, and the three wrong options are single terms taken from the same text. This is fast, but the questions can be easier than hand-written ones and are not a substitute for a reviewed assessment.

FAQ

Are the wrong options reliable?

They come from your own text, so review them before using in a test.

How many options does each question have?

Four options, labelled A to D, with the correct answer placed at random.

Is there an answer key?

Yes. The key appears after the questions.

Can I choose the difficulty?

Not directly. Longer and more varied source text gives better and harder questions.
